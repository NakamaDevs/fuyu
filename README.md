# Fuyu

Fuyu is a small browser game about identity, transformation, and the craft of acting. Its story and characters are original. Explore a side-scrolling world, enter isometric rooms, and learn abilities that open new paths.

## Run locally

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. To create and serve a production build:

```sh
npm run build
npm run preview
```

The game runs in the browser. It has no backend, accounts, analytics, API keys, or runtime AI calls. The selected language (Spanish by default, or English) is stored in browser local storage. Game progress is not saved; restarting begins a new session.

## Controls

| Key | Action |
| --- | --- |
| WASD or arrow keys | Move |
| Space | Run (uses energy) |
| Q | Jump; the later form jumps higher |
| J | Attack |
| K | Dash, after it is unlocked |
| E | Interact, enter or leave rooms, and advance dialogue |
| M | Open or close the discovered-room map |
| Escape | Pause or resume |

Movement, jumping, combat, and dashing work in both the side-scrolling areas and isometric rooms. Touch buttons are also available on small screens.

## Play

Collect the three elevated echoes and explore the connected rooms. Defeat each room's boss to open its isometric room. Interacting with the voice in the first room grants dash; the mirror room grants a higher jump and the final form. Use dash to break through the ivy barrier, then reach the upper exit. The map reveals rooms as you discover them and shows adjacent unexplored rooms.

Bottles restore health and energy when needed and do not respawn after use. Resting at a room's fountain restores both, resets common enemies, and sets the checkpoint while preserving boss defeats and upgrades. Taking fatal damage returns Fuyu to the checkpoint. Progress lasts only for the current page session.

## Gameplay laboratory

Open **Gameplay laboratory** below the game to load an isolated movement, combat, damage, dash, isometric, boss, fountain, or final-jump scenario. The lab displays live movement and combat metrics and can export the current state and recorded input trace as JSON. It can also record up to 10 seconds of the game canvas as WebM. Canvas recording contains game visuals only; it does not use a microphone or camera.

## Project notes

See [docs/development.md](docs/development.md) for the source layout, architecture boundaries, and development commands. Fuyu uses Vite and PixiJS; PixiJS is vendored in `public/vendor/`. The gameplay scene is drawn procedurally with Canvas 2D and presented through PixiJS. Portraits are illustrated assets; the scenery, gameplay characters, enemies, effects, and interface are generated by the project.
